# skillMatch
Repositório contendo projeto com skill match de funcionário com vaga.
# Calculo com diferentes pesos para percentual final:
Área pesa: 10%
Experiência: 20%
Habilidades: 70%

# O calculo para o percentual final utiliza:
->=80% para Alta compatibilidade,
 <=50 para média, 
 else 49% para baixa compatibilidade.
